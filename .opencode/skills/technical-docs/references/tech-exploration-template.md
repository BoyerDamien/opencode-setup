# Template Tech Exploration (proposition)

## Sections

1. **Context / Question à trancher** — quelle incertitude on cherche à lever, pourquoi maintenant.
2. **Pistes explorées** — pour chaque piste : description courte, avantages, inconvénients, effort estimé grossier.
3. **Findings** — ce qu'on a appris concrètement (tests, lectures de code, discussions).
4. **Recommandation** — une tech spec est-elle nécessaire ? Si oui, quel format (Tech Design complet ou lite) ? Estimation d'effort pour trancher.

## Note

Ce document alimente directement la decision table du SKILL.md (§ Decision table) : la Recommandation est ce qui déclenche ensuite un ADR, un Tech Design, ou un Tech Design lite.
